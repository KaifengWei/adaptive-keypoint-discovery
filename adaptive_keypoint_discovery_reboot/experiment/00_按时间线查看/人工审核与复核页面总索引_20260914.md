## 先看这三点

1. **页面、模型结果、人工意见是三种文件。** 旧 HTML 往往只保存待审核图像和交互程序；已填写意见通常另在 CSV/JSON，或暂存于当时浏览器的 `localStorage`。重新打开页面出现空白选择，不等于人工意见丢失。
2. **“待填写”不是“人工审核完成”。** G1 的双人表和 V3 的 11 张路径表目前没有已填写的人工字段；不能把自动评估或程序生成的解释 CSV 写成两位专家意见。
3. **当前门槛没有变化。** 三轮人工描迹已冻结，13 张分歧样本的双人共识及必要重描仍未完成；只读共识页不提交最终 GT。Teacher-direct/B/D 表型比较、正式消融、五随机种子和 V4 test 继续后置。

## 如何安全回顾旧结果

- 想看**模型训练后的外观**：先打开本表中对应阶段的结果图或 HTML，再看同一行的完成 CSV 和分析报告。不能拿另一版本的 CSV 配当前页面。
- 想看**当时人怎么判断**：以原始完成 CSV/JSON 为准。旧整株版须用 Git 提交 `f17f92e` 查原文件；当前同名 CSV 是方案 C，不可误用。三轮人工 GT 和裁决原始记录只在本地 `runtime`，不得复制进公开索引或 GitHub。
- 想在**原交互页看到已提交选择**：多数旧路径页只使用浏览器本地存储且没有 CSV 导入器；能够打开图，不代表能自动回放选择。三轮 GT 正式包有同包 JSON 恢复机制。若需要统一的“只读历史回放”，应以冻结导出生成独立页面，并标明重建，不改原 HTML 和原始提交。
- 2026-08-02 的完整协作包是当前可直接使用的四平台历史总入口；工程内 `experiment/manual_review_system/打开复核平台.html` 当前缺少它所引用的本地子目录，链接并不完整。
