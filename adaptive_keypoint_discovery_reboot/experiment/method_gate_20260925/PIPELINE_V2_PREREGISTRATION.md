## 1. 假设与唯一改动边界

**H1**：对已生成的数量可变 learned points，以不确定性感知、距离加权的关联替代 V1 单纯的 `d≤0.025D` 硬投影拒绝，可减少近结构点因小幅定位偏差造成的基部或拓扑崩塌，同时不造成相当或更大的假枝、错基部、多余路径及颖果/根系错误关联。

V2 **只改变** `learned point → 已有地上部骨架像素` 的接受判定；最近骨架投影位置、同像素重复合并、学习点作为唯一图节点、骨架测地最小生成树、局部 decoder 和表型几何均沿用 V1。不存在的候选不会被补造；本方案不能解决候选缺失或既有 decoder 对已入图短枝的剪除。Teacher-direct 与第 53 轮冻结 Student-B **共用完全相同的 V2 关联函数及常数**，不得一方使用 V1、另一方使用 V2。原 V1 文件和结果只读留存，V2 另存版本化输出。

不修改 Teacher、Student-B checkpoint/架构/heatmap/threshold/NMS、输入图、`phenotype_roi_v1`、`basal_transition`、局部 decoder、phenotype geometry、人工 GT、Core 12/Diagnostic 4 或 182/34 内部划分及 V4 220/40/40 划分；不训练、不调旧组件、不开发 V3。冻结 Student-B checkpoint SHA-256：`bb2fb948f60d5f3159893fee27493618caa416728f4e1d8d395099df98d19aa2`。

## 3. 唯一关联算法及全部常数

对两种方法逐图使用完全相同的已冻结输入和 518 像素坐标系。令 `S` 为原 `automatic_structural_support` 的布尔支持，`K` 为原 `prune_short_terminal_spurs` 后的骨架，`R` 为原 `phenotype_roi_model`，`B` 为原 `basal_transition_model`，`U` 为原 `seed_base_root_model`，`H` 为原 shoot 掩膜的同画布映射。`D=max(1, hypot(S 的包围框宽, 高))`，与 V1 同源。每个已有点 `p_i` 用 V1 相同的 `cKDTree.query(k=1)` 取得最近骨架像素 `q_i`；不搜索次近骨架、不变更投影位置及并列时的原实现行为。

定义 `d_i=||p_i-q_i||₂`。在 `S` 上按 OpenCV `DIST_L2/DIST_MASK_PRECISE` 求内部欧氏距离变换，`r_i=min(EDT_S(q_i), 0.0125D)`；这只是局部自动支持半宽的上限，不是手工器官宽度。把 `R` 的每个真值像素视为以像素中心为中心、边长 1 px 的闭方格，`δ_i` 为浮点坐标 `p_i` 到这些方格**并集**的最短欧氏距离：落在并集内为 0，外部按各方格最近边界求最小值。这样 `δ_i` 随点坐标连续变化，不依赖四舍五入。令

\[
\sigma_0=0.0125D,\qquad
\sigma_i=\sqrt{\sigma_0^2+r_i^2},\qquad
A_i=\exp\!\left[-\frac{d_i^2+\delta_i^2}{2\sigma_i^2}\right].
\]

仅当 `q_i∈R`、`q_i` **不**属于 `U∧¬H∧¬B`（地下部独占区），且 `A_i≥exp(-2)` 时接受该**原有学习点**为图节点；其余分别记 `outside_frozen_roi`、`root_only_association`、`weighted_association_rejection`。`K` 为空仍沿用 V1 的 `empty_skeleton` 失败。数值边界恰好相等时接受；非有限坐标/尺度或必需输入缺失则整次运行报错，不进行临时填补。原始 `score/confidence` 不乘进 `A_i`、不改写到下游；多个点投影到同一像素时仍按 V1 的原始置信度与原始输入顺序合并。每点须保存 `d_i,D,d_i/D,δ_i,r_i,σ_i,A_i`、ROI/地下部判定和最终拒绝原因。

参数来源已在此固定：`0.025D` 是**原 V1 已锁定的参照尺度**；把它解释为 `2σ₀`，故 `σ₀=0.0125D`。局部半宽只按 `EDT_S(q)` 测得并封顶于 `σ₀`；宽度系数、ROI 距离系数均为 1；接受分数为固定的 `exp(-2)`。**没有待校准参数、随机种子或 GT 选择步骤**。当 `r=δ=0` 时退化为 V1 距离判定；宽处可容忍更大偏移，ROI 外点则因 `δ` 连续受罚。由 `r≤σ₀` 可推出即便 `δ=0`，最大可能接受距离也不超过 `0.025√2 D≈0.03536D`；这只是公式的安全上界，**不是扫描或另选的全局投影阈值**。不得改变上述数值、加入第二套关联候选、按 `0002/0031/0005/0030` 加例外，或因 V2 的 phenotype 结果重新调函数。

## 5. 预先锁定的正负指标

所有计数先按 **Teacher-direct / Student-B 分开**、再按植株配对报告；有 GT 的指标再分 Core / Diagnostic。除总数外须列出所有 V1→V2 改变的点 ID、图像、投影距离、旧/新原因及是否进入最终 phenotype path。投影拒绝与同像素重复合并**分别**计数。

| 层级 | 正面指标 | 负面指标／口径 |
|---|---|---|
| 点—结构接口（40 val） | 超距拒点总数变化；`V1 projection_too_far → V2 accepted` 的几何 near-miss 数及其入图/入最终路径数；原 `base_selection_failure` 和零路径图数是否减少。这里的“几何 near-miss 恢复”不等于人工证实的真点。 | V2 新增接受节点、V1 已接受而 V2 拒绝的节点、重复合并变化；新基部失败、新零路径、额外预测路径及图边/终端变化。按 `d/D` 和 ROI/地下部位置分层，不以被接受本身计作成功。 |

## 6. V1 / V2 一次性裁决、失败与回退

采用**安全门槛先于收益门槛**的固定顺序；不以逐图印象、事后 p 值或某个方法的平均值改判。

**明显恶化 → 结果 3，回退 V1**：任一方法在 Core 或 Diagnostic 新增已确认的假侧枝／基部偏离事件、`U∧¬H` 节点或路径污染，或任一组可测 GT 匹配数减少、新增零路径图、无歧义的多余预测下界增加。GT 无法裁定的新增路径不得作为“无害”抵消这些事件。实现未通过哈希/回归/完整性检查也不得进入 V2 方法结论，保留 V1 并报告技术失败。

**有净收益 → 结果 1，冻结 V2**，须同时满足：① 至少两株不同 val 植株、且来自不同原始扫描帧的原超距学习点经 V2 **实际入图**，并且其**同株同点源**的原基部失败或零路径确实解除，而非只增加孤立节点；② 16 株中至少增加一条可测 GT 的正确路径匹配；③ Teacher 和 Student 各自在 Core、Diagnostic 的可测 GT 匹配数与路径精度**下界**均不下降；④ 无新增已确认假侧枝、基部偏离事件、地下部污染、零路径或无歧义多余路径，未匹配预测区间上界也不得升高；⑤ 在 V1/V2 都匹配的同一 GT 上，任何可评估方法×组的配对长度误差中位增量不得达到 `3.72` 个百分点、分化角误差中位增量不得达到 `17.08°`。这两个既有人类 MDC95 仅作保守的**实用退化警戒线**，不是显著性检验，也不证明统计等效。若一组无可比角度，记不可评估，不补值。

**无明确净收益 → 结果 2，回退并冻结 V1**：未触发明确恶化，但未满足全部净收益条件，包括只增加节点而不改善路径、只改善已知个例、收益仅在无 GT 的旧复核中出现、无曲线结构造成的真假歧义无法排除，或表型/安全代价互相抵消。Core 与 Diagnostic 均原样报告；允许 Diagnostic 修复成为净收益证据，但不得以其掩盖 Core 损失。无论结论 1/2/3，均记录全量成功与失败例，不进行第二个关联函数、阈值扫描、针对个例的规则补丁、重训 Student 或 V3。

本预注册只允许将来**一次**正式 V2 implementation/evaluation；当前阶段到此为止。最终冻结 V1 或 V2 后，方法开发停止，下一阶段须**另行**预注册 V4 locked test 最终评价；本文件不是 test 协议，当前绝不读取 test。
