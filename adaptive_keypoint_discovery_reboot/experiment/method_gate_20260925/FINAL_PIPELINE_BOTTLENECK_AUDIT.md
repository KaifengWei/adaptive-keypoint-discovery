# Final Pipeline Bottleneck Audit（冻结方法、V4 val，2026-09-25）

## 裁决

**BOTTLENECK = MIXED。**当前剩余表型／路径失败不能归结为“点没有学到”，也不能全部归结为下游接口。冻结的 Teacher-direct 与 epoch-53 Student-B 在锁定的 16 株 pilot 上有三种可验证的首要失败：确实缺少结构候选、候选在真实结构附近却被点—骨架硬投影拒绝、以及候选已经入图但短分支被 decoder 删除。表型匹配本身不是下文 10 条未匹配且有几何 GT 路径的首要失败原因。对 40 株历史人工路径复核中尚无逐叶几何 GT 的记录，不把“有拒点”自动判作“拒点造成漏叶”。

**是否足以在 V4 test 前研究唯一一个 final Pipeline V2：有条件地“是”。**`v4_val_0002` 与 `v4_val_0031` 是不同植株、不同原始扫描帧（`src_0347` / `src_0349`）上重复的“近基部学习点 → 冻结投影硬拒绝 → 无合格基部 → 零路径”链条；两株属于同一采集组，因此这不是跨采集条件的独立验证。`0002` 有冻结人工 GT 的两条路径，`0031` 只有旧 40 株人工路径复核与冻结 Teacher-direct 的对照，不能把它冒充第二株人工表型 GT。这个重复足以提出**一个**机制驱动假设，不足以宣称 V2 有效，也不足以改动 `0.025D`。本轮**未实现 V2，未扫描投影界限，未读取或预注册 V4 test**；Gate B 和 Student-B 的 frozen learned-surrogate 定位维持不变。

## 研究边界、输入与复核办法

- 两种冻结点源：Route B 九视图 Teacher-direct 与第 53 轮 Student-B。输入同为 V4 **val** 的 `phenotype_roi_v1`；下游共用现有点条件 graph、`local_learned_support` decoder 和 `phenotype-geometry-v1`。图的投影限仍为严格 `distance > 0.025 × D` 才拒绝，其中 `D` 是 518 像素画布上自动结构支持包围框对角线。
- 对 40 张 val × 2 点源逐张重建原有 graph/decoder，**80/80 的接受节点数和路径数与已保存冻结结果完全一致**。本审计只读取保存的点与图像／掩膜，使用既有 evaluator；没有重训或写回任何模型、点、ROI、阈值、投影、graph、decoder、GT 或几何参数。
- 人工表型归因仅用已经冻结的 Core 12 + Diagnostic 4（独立结构 34 条、其中 33 条有几何）；Core 和 Diagnostic 不合并为主结果。其余 24 株仅以 2026-08-03 现有人工路径复核作结构诊断，不能赋予未标的逐叶 GT 身份。历史 A/B/C/D 是不同冻结组合；其结论只作为既往复核线索，不充作当前 Teacher-direct 的逐株人工标签。
- 下表的“候选接近结构”依据原图位置、已保存 shoot/ROI 掩膜、Teacher 同株接受点及冻结人工路径；自动掩膜和点—点配对都**不是**人工关键点真值。`no_candidate` 指所需结构附近未生成可用候选；`localization_near_miss` 指有候选但偏离可投影的中心线；`projection_rejection` 是 graph 代码确实执行的过滤；其后才区分 `base_selection_failure`、`graph_connectivity_failure`、`decoder_pruning_failure` 和 `phenotype_matching_failure`。同一漏路径可有上游事件和下游后果，不重复计作独立样本。

## 唯一允许提出的 Pipeline V2 假设（尚未实施）

**H1：对已经生成的动态 learned points，采用 uncertainty-aware、distance-weighted 的 point-to-structure association，显式结合点位不确定性、局部地上部支持与结构连续性，可能减少硬门限在薄叶尖／基部造成的非连续丢失，同时保持离植株候选受抑制。**它改变的是候选与结构的关联方式，不是重新设定固定关键点，也不是对 `0.025D` 扫更宽的新阈值；不得为 `0002` 写特例，不得补造没有 learned point 的叶尖。此假设仅由两个独立植株的同机制基部崩塌及 `0005/0030` 的近终端拒绝启发；它不能解决 Teacher `0004` 的候选缺失、Student `0030` 另一条无候选路径，或 `0006` 的局部 Decoder 剪枝。

若用户以后单独授权开发，只允许**一个**事先锁定的 V2 实现与既有冻结 V1 作机制对照；关联函数／不确定性来源、训练或校准数据、失败门槛、假枝与错基部代价均须在运行前固定，不能用这些已看过的 val 个案或人工 phenotype GT 逐图调权重，也不能暗中修改模型、解码器或 GT。当前证据只是“有理由研究”，不是 V2 胜出，更不授权本轮动手。**到此停止；V4 test 维持未读取、未预注册、未解锁。**
