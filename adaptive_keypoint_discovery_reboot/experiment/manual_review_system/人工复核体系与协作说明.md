# 人工复核体系与协作说明

## 一、它在研究中的作用

人工复核用于验证“模型发现的点是否真正支撑正确器官路径”，属于评价流程，不属于训练流程。复核者不点击关键点坐标、不修改模型路径，也不为模型提供类别标签。

自动指标可以衡量重复性、前景命中、结构覆盖和曲线贴合，却不能可靠判断：

- 一条线属于叶片还是根须；
- 小叶是否遗漏；
- 两个不同器官是否被错误连接；
- 基部是否处于合理的shoot侧过渡位置。

因此，人工复核用于阻止“程序运行成功”被误写成“植物学语义正确”。

## 二、平台一：地上部有效域复核

每张图判断三个字段：

1. `manual_roi_completeness`：地上部是否完整；
2. `manual_seed_root_exclusion`：颖果和根须是否已排除；
3. `manual_basal_transition`：黄色基部过渡区是否位于shoot侧合理位置。

该平台验证模型输入域，不评价最终路径。

## 三、平台二与平台三：关键点条件器官路径复核

每张图判断四个字段：

1. `manual_path_semantics`：整体路径是否可以用于器官与表型解释；
2. `manual_missing_organ`：是否遗漏真实叶片或有效地上部；
3. `manual_wrong_connection`：是否跨越背景、串错器官或连入根须；
4. `manual_base_selection`：基部是否位于地上部起始过渡位置。

备注应描述具体位置，例如“上方短叶未恢复”“路径穿过白色背景”“基部偏向颖果”。

平台二是路线B基线，平台三是结构覆盖增强方案C。两者字段完全相同，便于配对比较。复核方案C时必须先独立完成平台三，不能一边查看平台四一边回填。

## 四、平台四：最终A/B/C/D配对复核

四种组合分别为：

- A：路线B教师 + 全局短枝阈值；
- B：路线B教师 + 局部尺度解码；
- C：结构覆盖教师 + 全局短枝阈值；
- D：结构覆盖教师 + 局部尺度解码。

该页不预设任何方案为推荐候选。每种方案分别记录：

1. 正确恢复的真实器官路径数；
2. 漏叶数；
3. 新增假枝数；
4. 是否存在错连；
5. 基部是否正确。

然后再判断A与B、A与C、C与D、B与D以及D相对A的变化。前四组分别隔离Decoder或Teacher的贡献；D相对A只描述完整组合变化，不能替代因果拆分。

这是冻结期最后一轮以肉眼路径语义驱动方法比较的审核。审核完成后，模型选择转入表型优先阶段。人工判断不回流成关键点坐标或Teacher修补规则。

## 五、独立复核要求

- 不先查看`用户完成示例`；
- 不根据自动分数、方案新旧或字母顺序猜测应该选什么；
- 原图优先于路径线条，必要时点击图片查看原尺寸；
- `uncertain`表示图像证据不足，不表示“差不多正确”；
- 完成后立即导出CSV，并保留原始文件；
- 发现平台问题时单独记录，不直接修改HTML或CSV列名。

## 六、多人一致性

建议第二名复核者独立完成40张有效域和40张路径审核。分类字段报告：

- 原始一致率；
- Cohen's kappa；
- 各类别混淆表；
- 分歧图像清单与最终裁决。

人工表型阶段的长度、角度等连续变量建议报告ICC、MAE，并使用Bland–Altman图检查系统偏差。原有“严格路径通过达到32/40才开始表型测量”的门槛已经取消；路径语义改为辅助解释，表型误差作为主要模型选择依据。
