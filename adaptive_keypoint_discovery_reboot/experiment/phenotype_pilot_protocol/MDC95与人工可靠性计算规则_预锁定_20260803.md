# MDC95 与人工可靠性计算规则（测量前预锁定）

状态：`locked_before_measurement`。本文件是协议 v2 第 6 节的计算实施清单，测量完成后不得改用更有利的公式。

## 1. 分析对象

- 长度与角度分别分析；不合成为总分。
- 长度同时保留 `px`、`bbox_norm`、`metadata_mm` 和对称相对差百分比。
- 角度单位为度。
- 曲率只作探索性重复性描述，不形成 MDC95 淘汰阈值。
- 只有同一参考 trace 在两次测量中均可测时才构成一对；缺失不插补，报告纳入对数和排除原因。

## 2. 差值、SEM 与 MDC95

对每个 endpoint 和每个有效配对，定义 `d_i = x_i2 - x_i1`：

```text
bias       = mean(d_i)
SD_diff    = sample standard deviation(d_i), denominator n-1
SEM        = SD_diff / sqrt(2)
MDC95      = 1.96 * sqrt(2) * SEM
           = 1.96 * SD_diff
BA_lower   = bias - 1.96 * SD_diff
BA_upper   = bias + 1.96 * SD_diff
```

相对长度以 `100 × (x2-x1)/mean(x1,x2)` 先逐对计算，再对该差值序列应用同一公式。若两次值均为 0，则该对相对长度记为不可计算，不人为赋 0。

## 3. 两类可靠性

### 3.1 Intra-rater

- 配对：Rater 1 round 2 − Rater 1 round 1。
- 数据：全部 16 张中能够在两轮稳定匹配的人工 trace。
- ICC：双向混合、绝对一致、单次测量 `ICC(A,1)`，报告点估计和 95% CI。

### 3.2 Inter-rater

- 配对：Rater 2 round 1 − Rater 1 round 1。
- 推荐：全部 16 张；最低：全部 Core 12。
- Core 12 为主可靠性估计；若 Diagnostic 4 也完成，单独提供描述，不并入 Core 方法比较。
- ICC：双向随机、绝对一致、单次测量 `ICC(A,1)`，报告点估计和 95% CI。

## 4. 后续方法判定使用的误差底线

每个 endpoint 的人工误差底线固定为：

`measurement_floor = max(MDC95_intra, MDC95_inter)`。

方法间差异必须超过相应单位和 endpoint 的误差底线，才可解释为超出人工测量噪声。长度优先使用相对 MDC95 进行跨株解释，并同时给出 px、bbox-normalized 和标注为 `derived from scanner metadata` 的 mm 结果；角度使用 degree MDC95。

## 5. 置信区间与敏感性分析

- MDC95、bias、Bland–Altman 限和方法效应的区间采用按植株重采样的 cluster bootstrap。
- bootstrap 必须保持同株多叶为一个簇，不能把叶片当成独立样本。
- `SD_pooled × sqrt(1-ICC)` 仅作为预先声明的敏感性分析，不替代主 SEM/MDC95 定义。
- 不因结果不理想而更换 ICC 类型、差值方向、缺失处理或主尺度。

## 6. 输出字段

每项输出至少包含：`endpoint`、`unit`、`comparison_type`、`n_plants`、`n_trace_pairs`、`bias`、`sd_diff`、`sem`、`mdc95`、`ba_lower`、`ba_upper`、`icc_type`、`icc`、`icc_ci_lower`、`icc_ci_upper`、`bootstrap_cluster=plant`、`missing_pair_count`。
