## 阶段结论与下一门槛

这轮 pilot **完成了冻结方法的表型比较，但没有选出统计上可信的最终赢家**。B 比直接教师少一些多检、匹配路径长度中位误差略低，却没有增加 Core 几何召回，逐株配对收益不足以超过人工误差底线，而且在 `v4_val_0030` 和 Diagnostic 样本漏掉 Teacher 能找到的结构。D 对 B 的整体覆盖完全不增，细微收益与代价交错；没有证据支持现在继续开发 D。

因此可以保留 **Teacher-direct 为强基线、Student-B 为待充分训练验证的最小学习型候选，D 为冻结消融对照**，但不能把“B 已胜出”写进论文。若论文需要学习型自动标注这一主张，下一步应在**事前锁定**训练轮数/早停、随机种子、模型选择规则和 test 解锁条件后，再对 B 进行充分训练与消融；不能根据这 16 株 GT 逐图调模型。用户若选择先以 Teacher-direct 作为简洁方法，也应把 B 的结果作为未能证明增益的对照，而不能掩盖失败。正式训练、五随机种子、V4 test 和表型准确率“通过”的表述目前均未启动或成立。
